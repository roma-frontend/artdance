# Перенос макета в компоненты

Эталон: `design/reference/artdance-final.html` — утверждённый клиентом дизайн.
Карта: `src/design/component-manifest.ts` — что строить и с какими состояниями.

## Порядок работы над компонентом

1. Найди его в `componentManifest`: `prototypeClasses` покажут, какие именно
   стили переносить, `states` — чек-лист приёмки, `i18n` — namespace,
   `image` — preset.
2. Открой эталон, найди эти классы, перенеси **поведение**, а не CSS дословно:
   значения заменяются токенами.
3. Реализуй все состояния из `states`. Пустое состояние обязательно — в макете
   его нет ни у одного списка, это самый частый пробел при переносе.
4. `npm run design:status` — проверь, что класс закреплён и ничего не потеряно.

## Соответствие токенов

Токены прототипа уже перенесены в `src/design/tokens/`. Совпадение точное:

| Прототип | Токен |
|---|---|
| `--accent: #8b1a2b` | `accent` |
| `--gold: #b89a5e` | `metal` |
| `--bg: #f6f2ed` | `surface-canvas` |
| `--card: #ffffff` | `surface-card` |
| `--text` / `--text2` / `--text3` | `content-primary` / `-secondary` / `-tertiary` |
| `--border: #e8e2da` | `border-default` |
| `--r-sm/md/lg/xl` 6/10/16/24px | `rounded-sm/md/lg/xl` |
| `--ease: cubic-bezier(.16,1,.3,1)` | `ease-brand` |
| `--max-w: 1320px` | `.page-container` |
| Playfair Display / DM Sans | `font-display` / `font-sans` |

Если в макете значение, которого нет в токенах — добавь токен, не пиши литерал.

## Что в макете сделано «на живую» и требует доработки

Прототип — статический HTML. При переносе обязательно добавить то, чего в нём нет:

- **Пустые, загрузочные и ошибочные состояния** — отсутствуют полностью.
- **Доступность**: звёзды рейтинга без текстовой альтернативы, кнопки карусели
  без `aria-label`, иконки-эмодзи вместо `lucide-react`, контраст `--text3` на
  ivory ниже 4.5:1 — для вспомогательного текста использовать
  `content-secondary`, не `-tertiary`.
- **`prefers-reduced-motion` не учтён нигде**, а движения в версии от 02.09.2026
  стало втрое больше: параллакс hero, параллакс секций, появление всех секций,
  трейл видео, свечение под курсором. Это уже не косметика — без обработки
  настройки часть пользователей получит непригодную страницу. Список того, что
  отключается, — `reducedMotionDisables` в `src/design/motion.ts`.
- **Фоновое видео hero**: 21,6 МБ, `autoplay` без `poster` и без `preload`,
  трейл до шести копий `<video>`. Требования — `videoProcessing` в
  `src/config/media-processing.ts`; кнопка паузы обязательна (WCAG 2.2.2).
- **`100vh` у hero** → `100dvh`, иначе первый экран дёргается на iOS.
- **`display: … !important`** в `.booking-grid`, `.cart-grid`, `.class-grid` —
  перебивание inline-стилей макета. В продукте сетка задаётся один раз.
- **Фильтры поиска исчезают на 360px** (`display: none !important`) — в продукте
  они уходят в `Sheet`, а не пропадают.
- **Hover-состояния на touch**: `Quick Add` у товара и `♡` у карточки занятия
  появляются только на hover — на телефоне они недостижимы.
- **Битая картинка на checkout**: в эталоне у одного `<img>` потерян префикс
  `photos/`. Не воспроизводить.
- **Тёмная тема** объявлена, но hero и editorial остаются тёмными в обеих темах:
  это `surface-cinema`, а не тема.

## Числа анимаций — в `src/design/motion.ts`

В макете параметры движения заданы литералами в inline-JS (`SLIDE_PX`,
`GHOST_EVERY`, `MAX_GHOST`, пороги observer, множители параллакса). В коде они
берутся из `motion.*`: «сделайте появление секций поспокойнее» должно быть
правкой одной строки, а не поиском магических чисел по десяти компонентам.

## Точки перелома

Макет использует пять: 360, 480, 768, 1024 и 1441px. Все есть в
`breakpoint` (`xxs`, `xs`, `md`, `lg`, `wide`). Медиазапросы в макете написаны
от большего к меньшему (`max-width`), в проекте Tailwind работает наоборот —
переносится поведение на каждой ширине, а не порядок правил.

## Данные для разработки

`npm run db:seed` наполняет БД контентом из макета (`prisma/fixtures/demo.ts`):
те же инструкторы, занятия, цены, залы, товары и события. Не выдумывай тестовые
данные — используй эти, тогда результат сравним с макетом один-в-один.

Изображения после `npm run design:import` лежат в `public/media/seed/` под
семантическими именами (`hero-dancer`, `instructor-anna-mkrtchyan`,
`style-salsa`). Соответствие оригиналам — `design/asset-manifest.ts`.
