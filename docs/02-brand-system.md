# Брендовая система ArtDance

Источники: `cis-guide (2).pdf` (ArtDance Brand Guide 2026, вариант «Ivory / Ink /
Crimson») и утверждённый прототип `artdance-landing/final.html`.

Всё, что описано ниже, **уже реализовано** в `src/design/tokens/`. Этот документ
объясняет решения; значения смотрите в коде — он источник правды.

---

## 1. Реконсиляция гайда и прототипа

Гайд и прототип расходились в двух местах. Оба расхождения решены в пользу
конкретной роли, а не в пользу одного из документов.

### Акцентный цвет

| | Гайд | Прототип |
|---|---|---|
| Акцент | `#6E1422` электрический красный | `#8B1A2B` бургунди |
| Кинематографичные плоскости | `#6E0F1C` бургунди | `#0D0B09` почти чёрный |
| «Металл» | нет | `#B89A5E` золото |

**Решение — развести по ролям, а не выбирать одно.** Гайд сам подсказывает
формулировку: «электрический красный — это сигнал, а не поверхность».

| Роль (токен) | Значение | Где применяется |
|---|---|---|
| `accent` | `#8B1A2B` | основные кнопки, активная навигация, выбранные фильтры и слоты, ключевые цены |
| `signal` | `#6E1422` | «осталось 3 места», «идёт сейчас», ошибки, urgency |
| `surface-cinema-alt` | `#6E0F1C` | полноэкранные editorial-секции |
| `metal` | `#B89A5E` | бейдж «проверен», звёзды рейтинга, тонкие премиальные разделители |

Это сохраняет визуал, который клиент уже одобрил, и одновременно исполняет
правило гайда «если красного на экране больше нескольких элементов — уберите один».

`danger` намеренно равен `signal`: вводить четвёртый красный только ради ошибок
раздробило бы палитру. Ошибка отличается иконкой и контекстом, а не оттенком.

### Гарнитуры

| | Гайд 3 | Гайд 2 | Прототип | **Решение** |
|---|---|---|---|---|
| Заголовки | Satoshi | Neue Haas Grotesk | Playfair Display | **Playfair Display** |
| Текст | Inter | Geist | DM Sans | **DM Sans** |

Playfair Display + DM Sans — то, чем достигнут «editorial luxury» в утверждённом
прототипе; Satoshi даёт другой, более технологичный характер. Плюс обе выбранные
гарнитуры под лицензией SIL OFL и подключены self-hosted через `next/font`:
ноль внешних запросов в runtime, ноль юридического риска.

Neue Haas Grotesk из гайда 2 — платная лицензия, отклонена.

Для армянского добавлена **Noto Sans Armenian**: ни Playfair, ни DM Sans не
покрывают армянский алфавит. Подключается автоматически по `:lang(hy)` — обёрток
в разметке не требуется.

## 2. Палитра как система

Токены живут в двух слоях. Компоненты видят только второй.

```
primitives.ts          semantic.ts              компонент
────────────────       ─────────────────        ──────────────────
ivory[200] #F7F4EF  →  surface-canvas       →   bg-surface-canvas
ink[900]   #141414  →  content-primary      →   text-content-primary
crimson[600] #8B1A2B → accent               →   bg-accent
```

Пять брендовых рамп: `ivory` (тёплая «бумага», 45% использования), `ink`
(near-black, 25%), `crimson` (акцент, 15%), `gold` (металл, 10%), плюс статусные
`green` / `amber` / `blue`.

Тёмная тема — не отдельный дизайн, а второй набор значений для тех же ролей.
`surface-cinema` при этом **не зависит от темы**: hero и editorial-секции всегда
кинематографично тёмные, как в прототипе. Это соответствует правилу гайда:
чёрный — для editorial-заявлений, а не как тема всего сайта.

На тёмном фоне акцент поднимается на шаг светлее (`crimson[500]`) — бургунди
`#8B1A2B` на почти чёрном не проходит по контрасту.

## 3. Типографика как роли

Вместо шести CSS-свойств на каждый заголовок — 17 именованных стилей:
`display-hero`, `display-editorial`, `heading-1…4`, `card-title`, `quote`,
`body-lg`, `body`, `body-sm`, `caption`, `eyebrow`, `label`, `button`, `price`,
`numeric`.

Применение: `<h2 className="text-heading-2">` или `data-text="heading-2"`.
Размеры — fluid `clamp()`, поэтому промежуточных брейкпоинтов для типографики
не требуется.

`eyebrow` — надзаголовок секции из прототипа: `Discover`, `Meet the Masters`,
`Popular Right Now`.

## 4. Что ещё формализовано

- **Сетка**: контейнер 1320 px, боковой отступ `clamp(1.25rem, 4vw, 3rem)`,
  вертикальный ритм секций в трёх плотностях (обычная / плотная / широкая).
- **Радиусы**: 6 / 10 / 16 / 24 px и `full` — как в прототипе.
- **Движение**: брендовый `cubic-bezier(0.16, 1, 0.3, 1)`, шкала длительностей,
  включая 40 s для marquee и 12 s для эффекта Кена Бёрнса в hero.
  Всё уважает `prefers-reduced-motion`.
- **Слои** (`z-index`): именованная карта от `base` до `commandPalette` — магические
  числа в компонентах запрещены линтером.
- **Вуали на фото** (`scrim`): четыре готовых градиента, включая диагональный
  hero-градиент и радиальный editorial — точные значения из прототипа.
- **Соотношения сторон**: `portrait 3:4` для карточек направлений, `16:10` для
  занятий, `1:1` для инструкторов, `2:3` для товаров, `21:9` для кинематографичных
  полос. Используются и в CSS, и в `next/image`.
- **Медиа-presets**: 12 ролей изображений, у каждой зафиксированы `sizes`,
  `quality` и `priority`. Это защищает LCP: рассинхрон `sizes` и реальной сетки —
  главная причина плохого Core Web Vitals.

## 5. Голос бренда

Из гайда, реализовано в тональности `src/i18n/messages/`:

**Мы**: прямые, энергичные, editorial, человечные, уверенные.
**Мы не**: корпоративные, кричащие, милые, расплывчатые, навязчивые.

> Так: «Latin Fusion с Анной. Суббота, 18:00, Ереван. Осталось 8 мест.»
> Не так: «Оптимизируйте свой танцевальный путь с нашей инновационной
> all-in-one платформой бронирования!»

Практическое следствие для интерфейса: конкретика вместо обещаний. Цена, время,
имя инструктора, количество свободных мест — раньше, чем прилагательные.

## 6. Открытый вопрос к заказчику

Один пункт требует подтверждения перед финальной вёрсткой: **основной акцент —
бургунди `#8B1A2B` (как в одобренном прототипе) или электрический красный
`#6E1422` (как в брендгайде)?**

Смена решения стоит одну строку в `src/design/tokens/semantic.ts` и не затрагивает
ни один компонент — но лучше зафиксировать её до отрисовки макетов, чтобы
презентация клиенту и код совпадали.
