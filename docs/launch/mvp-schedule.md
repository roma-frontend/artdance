# Недельный график до MVP: 21.09 — 20.12.2026

Расчёт от сегодняшнего дня до договорного срока — 3 месяца (20 декабря).
Логика: код идёт по критическому пути **бронирование → кабинеты → магазин →
платежи → запуск**, а всё, что не код (банки, юрист, домен, вычитка),
стартует **параллельно на первой неделе**, потому что у каждого из этих
путей свой долгий латентный период.

Ответственные: **Р** — разработчик, **З** — заказчик, **Ю** — юрист,
**Н** — носитель армянского, **Б** — банк.
