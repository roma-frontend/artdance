## Перед коммитом

- Не закоммичено: кабинет инструктора, назначение залов, правка `e2e/partner-dashboards.spec.ts`.
- Локальный e2e не запускался: служба Postgres `postgresql-x64-17` отключена. Для запуска нужен админ-доступ: `Set-Service -Name postgresql-x64-17 -StartupType Manual` и `Start-Service -Name postgresql-x64-17`.
- Миграции и сид запускать только на localhost (явно задать `DATABASE_URL` и `DIRECT_DATABASE_URL`). Не запускать против Supabase.
- Пушить только после зелёного CI и подтверждения пользователя.
- Армянские строки (`hy`) нужна проверка носителем языка.
