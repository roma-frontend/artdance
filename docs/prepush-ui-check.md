# Проверка UI и готовности к пушу — 9 октября 2026

## Инструктор без занятия

`/[locale]/instructors/[slug]/book` различает три состояния:

- Публичный профиль и опубликованное занятие: существующий календарь и бронирование.
- Публичный профиль без занятия: HTTP 200, `no-store`, `noindex`, оформленный `EmptyState`, имя инструктора, объяснение и ссылки на каталог занятий/профиль. Без календаря, выдуманной цены, оплаты и запросов удержания.
- Отсутствующий/непубличный профиль, неизвестный явно заданный `?class=`, пустой или повторённый параметр: настоящая 404.

Контент-слой возвращает `BookingContent | InstructorBookingEmpty | null`. Ветка `InstructorBookingEmpty` имеет `kind: 'no-classes'`, `instructorSlug`, `instructorName`. Тексты — `booking.noClasses*`, `browseClassesCta`, `backToInstructorCta` в hy/ru/en. Цвета/типографика/отступы — существующие семантические токены; компоненты — существующие `EmptyState`, `Button`, locale-aware `Link`, пути — `routes`.

Профиль без занятий больше не обещает доступную индивидуальную запись. CTA профиля открывает объяснение, а не 404. Пустое состояние использует две кнопки высотой минимум 44 px с переносом длинного перевода.

## Дополнительные найденные несоответствия

- `/search` — действующий алиас с redirect на `/discover`, не отдельная индексируемая страница. Удалён из sitemap, прямые ссылки продолжают работать. Добавлена регрессия состава карты.
- Проверка размера аккордеона ранее могла измерить SSR percentage fallback до первого ResizeObserver. Теперь ждёт инициализированную фиксированную геометрию; строгие проверки одинакового размера и времени запуска декодера сохранены. В широком прогоне проходит на всех трёх устройствах.
- Матрица десяти axe-аудитов вынесена в десять отдельных тестов вместо одного: прежний сценарий превышал 30 секунд, независимо от исправности UI. Таймауты и утверждения не ослаблялись.

## Границы проверки

Локальный env подключён к удалённой БД. Миграции, сид и сценарии записи броней/платежей/админских мутаций против неё не запускались. Полный CI использует отдельный PostgreSQL: эти сценарии должны подтверждаться новым GitHub Actions run после пуша. Публичные проверки — чтение; контактная отправка исключена из локального прогона.

Автоматическая проверка не доказывает отсутствие абсолютно всех дефектов во всех возможных состояниях. Performance 100/100 и плавные 60 fps на любом слабом устройстве не заявляются; ограничения предыдущих замеров — в `ui-performance-audit.md`.
