# Support / God Mode — operator manual

Этот документ описывает безопасный рабочий поток поддержки в админке. Все функции
доступны только оператору с действующей capability-сессией; обычный пользователь
не получает доступ к этим страницам, API или серверным действиям.

## Global search и preview

На любой странице админки нажмите `Ctrl+K`, чтобы открыть глобальный поиск.
Поиск выполняется с debounce, отменяет устаревший запрос и показывает отдельные
состояния загрузки, пустого результата и ошибки. Стрелки `↑`/`↓` выбирают запись,
`Enter` открывает её, `Esc` закрывает палитру. Public search на маршрутах `/admin/*`
не перехватывает этот хоткей.

Результат можно открыть в split-view preview. Preview:

- читает только разрешённые модели `User`, `Order`, `Booking`, `SupportTicket`;
- возвращает ограниченные поля через Prisma `select`, а не полный объект;
- маскирует секреты и чувствительные значения;
- не создаёт и не изменяет запись;
- использует `Cache-Control: no-store` и проверку `requireOperator()`.

Если нужна полноценная работа с сущностью, используйте ссылку на штатную страницу
админки, а не пытайтесь расширять preview до универсального JSON-дампа.

## User 360

Страница пользователя показывает единый timeline из разрешённых источников:
создание пользователя, бронирования, заказы, обращения в поддержку, отзывы,
сессии и audit activity. Временные значения нормализуются в ISO-формат, выдачи
ограничены по размеру, а данные выбираются через явные Prisma `select`.

Timeline — инструмент диагностики, не замена журналу аудита. Не копируйте его
содержимое в тикеты или внешние чаты без необходимости: там могут быть PII и
операционные детали.

## Быстрые действия

На User 360 доступны:

- копирование user ID;
- копирование email;
- отзыв всех сессий пользователя.

Отзыв сессий:

1. Завершает активные сессии пользователя, кроме текущей сессии оператора.
2. Не блокирует пользователя и не меняет его профиль.
3. Записывает audit action `session.revokedAll`.
4. Требует явного подтверждения в интерфейсе.

Оператор не может отозвать собственную operator-сессию этим действием. Для
массовых или нестандартных операций используйте отдельный согласованный процесс,
а не терминал браузера.

## Проверки перед публикацией

Минимальный локальный набор:

```bash
npm run typecheck
npm run lint
npm run i18n:check
npm test
npm run build
```

Локальный каталог `.claude/worktrees/` игнорируется Git и отсутствует в GitHub
Actions. Скрипт `npm run lint` уже исключает этот артефакт:

```bash
npm run lint
```

После push ориентируйтесь на новый GitHub Actions run текущего commit SHA, а не
на старую зелёную историю. CI дополнительно проверяет Prisma, миграции, сборку,
security headers и браузерные сценарии.
