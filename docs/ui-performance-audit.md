# UI и производительность — 9 октября 2026

## Исправления

- Выбор места бронирования: заголовок внутри карточки, непрерывная рамка, доступное имя радиогруппы, подсветка клавиатурного фокуса.
- Нативный ползунок серии: брендовый accent вместо системного синего, увеличенная зона управления.
- Общие detail/booking/checkout grids: `minmax(0, 1fr)` вместо автоматически растущей минимальной ширины.
- Lite: остановка JS параллакса секций/подвала, прожектора, вращения печатей, stack cards, cinema aperture и style rail; очистка при переключении режима.
- Lite: статичная стопка, без brightness/blur/backdrop-filter и бесконечного блика заголовка; hover-отклик карточек сохраняется.
- Stack cards: все чтения геометрии перед записью; неизменившиеся значения не записываются повторно. Cinema aperture также читает геометрию пакетно.
- Style rail не перезаписывает неизменившийся запас высоты на каждом кадре.
- Scroll seal реагирует на изменение системной reduced-motion настройки во время работы.

## Производительность

Запуск: `node scripts/measure-ui-performance.mjs` при работающей production-сборке на порту 3100. Другой адрес: `PERF_BASE_URL=http://...`. Chromium, 1440×900, CPU slowdown ×4, 3 запуска на режим, прокрутка 4 секунды. Скрипт также сравнивает прежний/пакетный расчёт stack cover и проверяет равенство результата.

Медианы после изменений:

| Режим | p95 интервала кадров | Script | Layout | Recalc styles |
| --- | ---: | ---: | ---: | ---: |
| Full | 100 мс | 1553,3 мс | 42,5 мс | 714,0 мс |
| Lite | 133,4 мс | 1625,2 мс | 35,6 мс | 426,2 мс |

При этих условиях плавные 60 fps НЕ достигнуты. Полная страница включает lazy loading, видео и появления, поэтому эти цифры — сценарный замер, не чистый benchmark одного эффекта.

Парный расчёт stack cover (4 карточки × 100 итераций, 6 пар) дал медианы 23,95 мс для прежнего алгоритма и 21,1 мс для пакетного. Результаты геометрии совпали во всех парах. Разброс велик: в отдельных парах пакетный вариант медленнее, поэтому гарантированный процент ускорения не заявляется.

Исходные замеры шли параллельно с браузерными тестами; сравнение их wall-clock с итоговыми некорректно. Надёжное доказательство Lite — регрессионная проверка: после переключения нет записей style у отключённых параллаксов/печатей/stack при прокрутке; возврат Full снова запускает эффект.

## Не завершено

- Не проведён полный визуальный аудит всех страниц, административных экранов и состояний.
- Lighthouse оценки 100 не измерены и не достигнуты доказанно.
- Нужен изолированный профиль CPU/rendering на слабом устройстве и разбор оставшихся длинных кадров.
- Нужен аудит CDN-медиа, реальной сети и production Core Web Vitals.
- Контраст брендового бургунди остаётся ранее принятым отклонением проекта, не менялся без согласования.
- Нужна стабилизация геометрии мобильного аккордеона при первом измерении.
