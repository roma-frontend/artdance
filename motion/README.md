# ArtDance — презентационный ролик

Моушн-ролик 60 секунд, 16:9, 1920×1080, 30 fps, **три языковые версии**.
Сделан кодом в Remotion, рендерится локально, без After Effects.

Файлы для показа лежат в R2 и отдаются по CDN — локально держать копии не нужно:

| Язык | Ссылка |
|---|---|
| русский | `https://pub-3a0600ebdb9946a09619fd872274be49.r2.dev/promo/artdance-ru.mp4` |
| English | `https://pub-3a0600ebdb9946a09619fd872274be49.r2.dev/promo/artdance-en.mp4` |
| հայերեն | `https://pub-3a0600ebdb9946a09619fd872274be49.r2.dev/promo/artdance-hy.mp4` |

Ключи стабильные (без хеша в имени): ссылка попадает в письма и презентации,
и меняющийся адрес там дороже, чем необходимость сбросить кеш при обновлении.
Перезалить после перерендера — `npm run promo:upload` из корня проекта; команда
проверяет размер и content-type каждого объекта HEAD-запросом.

Видео собрано с `-movflags +faststart` (moov в начале файла), поэтому плеер
начинает играть, не дожидаясь загрузки всех 34 МБ. Без этого флага ролик
с R2 открывался бы с задержкой — проверено, первая сборка была именно такой.

Локальных копий ролика в репозитории нет: они уже на CDN, а пересобрать их
можно из исходников. Что лежит на диске и что восстанавливается:

| Путь | Размер | Нужен для перерендера | Восстановление |
|---|---|---|---|
| `src/`, `scripts/` | 160 КБ | да — исходники сцен | в репозитории |
| `public/fonts`, `public/sfx`, `public/track.mp3` | 2.4 МБ | да — шрифты, звук, трек | в репозитории |
| `public/assets` | 31 МБ | да — ассеты проекта | `npm run assets` |
| `node_modules` | 866 МБ | да — пакеты Remotion | `npm install` |
| `work/` | ~380 МБ | нет — черновики и кадры проверки | создаётся рендером |

## Три языка

Каждая локаль — отдельная композиция: `ArtDance-ru`, `ArtDance-en`, `ArtDance-hy`.
Все тексты в одном файле — `src/locales.ts`, взяты из каталогов проекта
(`src/i18n/messages/`), а не переведены «на слух».

Шрифты у языков разные, и это не прихоть:

| Локаль | Заголовки | Текст | Почему |
|---|---|---|---|
| ru | Playfair Display | Manrope | У DM Sans нет кириллицы |
| en | Playfair Display | DM Sans | Пара проекта |
| hy | Noto Serif Armenian | Noto Sans Armenian | Playfair и Manrope не покрывают армянский |

Размеры заголовков и хука масштабируются под язык (`TITLE_SCALE`, `WIDTH_FACTOR`):
армянские глифы шире латинских, и без коэффициента строка выходит за кадр.

## Мир

Тёмная сцена: бархат, прожектор, пыль в луче. Палитра — брендовая из
`src/design/tokens/`: ink `#141414`, бургунди `#8B1A2B`, золото `#B89A5E`,
ivory `#F7F4EF`. Материал — реальные ассеты проекта: лупы `hero-loop`,
`editorial-loop`, `competition-loop`, видео-плитки направлений, фото
инструкторов, залов и товаров. Ничего не сгенерировано, мир совпадает с сайтом.

Свет и звук идут от музыки: `src/levels.json` (покадровые bass/mid/high) и
`src/beats.json` (доли). Поэтому прожектор дышит в такт, а смены этапов стоят
на сильных долях, а не на равных интервалах.

## Перерендерить

**Первый запуск после клонирования** — поставить пакеты и подтянуть ассеты
проекта (они не лежат в репозитории: это копия сборки, 31 МБ):

```bash
cd motion
npm install
node scripts/copy-assets.mjs
```

Одна локаль:

```bash
cd motion
npx remotion render src/index.ts ArtDance-ru out-ru.mp4 --concurrency=3 --crf=17
```

Все три сразу:

```bash
cd motion
for L in ru en hy; do npx remotion render src/index.ts "ArtDance-$L" "out-$L.mp4" --concurrency=3 --crf=17; done
```

Черновик для быстрой проверки правок (в 2.5 раза быстрее):

```bash
cd motion
npx remotion render src/index.ts ArtDance-ru work/draft.mp4 --scale=0.35 --concurrency=3 --crf=28
```

Нормализация громкости до −14 LUFS и faststart, видео не пережимается:

```bash
cd motion
ffmpeg -i work/f-ru.mp4 -c:v copy -af "volume=2.35dB" -c:a aac -b:a 192k -movflags +faststart out-ru.mp4
```

Усиление `+2.35 dB` посчитано из замера: исходник даёт −16.35 LUFS, цель −14.
`loudnorm` в один проход здесь даёт −13.0 — динамический режим перебирает
громкость, поэтому применяется простой `volume` с проверкой результата.

`-movflags +faststart` обязателен: без него `moov` уезжает в конец файла, и
плеер ждёт полной загрузки 34 МБ вместо того, чтобы начать играть.

Публикация на CDN — из корня проекта:

```bash
npm run promo:upload
```

## Где что править

| Файл | Что в нём |
|---|---|
| `src/locales.ts` | **Все тексты и цифры на трёх языках.** Правка подписи — здесь |
| `src/stages.ts` | **Тайминги и раскладки этапов.** Сдвиг этапа — одна строка |
| `src/brand.ts` | Палитра ролика (копия токенов проекта) |
| `src/World.tsx` | Мир: задник, прожектор, пыль, зерно, виньетка |
| `src/Stage.tsx` | Каркас сцены этапа: подпись, карточки, четыре раскладки |
| `src/Intro.tsx` | Хук: занавес и первая фраза |
| `src/Outro.tsx` | Финал: сборка лого и три факта |
| `src/ArtDance.tsx` | Склейка сцен, свет по музыке, звук |
| `src/levels.json` | Покадровый bass/mid/high трека |
| `src/beats.json` | Доли и сильные удары трека |

Музыка: `public/track.mp3` — Mixkit Stock Music Free License (трек «Silent
Descent», окно 55–115 с). Звуки: `public/sfx/`, синтезированы `scripts/make_sfx.py`.

## Замена музыки

```bash
cd motion
ffmpeg -i <новый трек> -ar 44100 -ac 1 work/wav/film.wav
python -I scripts/beats.py work/wav/film.wav work/beats.json
python -I scripts/levels.py work/wav/film.wav 30 src/levels.json
```

Дальше поправить в `src/stages.ts` секунды `start`/`end` под новый ритм —
подписи и свет подхватят их автоматически.

## Проверено и не проверено

**Проверено:** кадры на всех шести этапах и склейках в каждой из трёх локалей,
длительность 60.1 с, громкость −14.0 LUFS и пик −1.8 dBTP, все элементы внутри
безопасных полей кадра (120 px от краёв).

**Не проверено:** ролик целиком в реальном времени — рендер кадр за кадром не
даёт оценить, как звук ложится на картинку. Если ритм не понравится, правьте
`start` в `src/stages.ts`.
