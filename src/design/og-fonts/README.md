# Шрифты для карточек в соцсетях

Файлы нужны рендереру `src/lib/seo/og-image.tsx`, который собирает
`opengraph-image` (1200×630). Ни браузер, ни `next/font` их не грузят — они
читаются с диска на сервере в момент отрисовки картинки.

## Почему отдельная копия шрифтов

`next/font` скачивает Google Fonts в сборку в формате **woff2**, а движок
отрисовки картинок (satori внутри `next/og`) понимает только **ttf, otf и woff**.
Переиспользовать то, что уже лежит в `.next`, нельзя, а скачивать шрифт по сети
в момент сборки — значит поставить сборку в зависимость от доступности внешнего
хоста.

Вариативные файлы из репозитория Google Fonts (`PlayfairDisplay[wght].ttf`) тоже
не подходят: парсер падает на таблице `fvar`
(`TypeError: Cannot read properties of undefined` в `parseFvarAxis`). Поэтому
здесь статические экземпляры из пакетов Fontsource, порезанные по алфавитам —
суммарно 111 KB на шесть файлов.

## Состав

| Файл | Алфавит | Начертание | Роль на карточке |
|---|---|---|---|
| `playfair-display-latin-400-normal.woff` | латиница | 400 | подписи, строка деталей |
| `playfair-display-latin-700-normal.woff` | латиница | 700 | заголовок |
| `playfair-display-cyrillic-400-normal.woff` | кириллица | 400 | то же по-русски |
| `playfair-display-cyrillic-700-normal.woff` | кириллица | 700 | то же по-русски |
| `noto-sans-armenian-armenian-400-normal.woff` | армянский | 400 | армянская локаль и знак ֏ |
| `noto-sans-armenian-armenian-700-normal.woff` | армянский | 700 | армянский заголовок |

Кириллица и латиница объявлены **разными семействами** (`Display` и
`DisplayCyrillic`), хотя это одна гарнитура. Причина в движке: два файла под
одним именем и с одним начертанием не складываются в один набор глифов —
побеждает первый, и русский заголовок молча уезжает в системный шрифт. Разные
имена в цепочке `fontFamily` дают правильный подбор по глифам.

DM Sans, которым набран интерфейс, на карточке не используется: у него нет
кириллического подмножества (`src/design/fonts.ts` подключает только `latin`), и
русский текст на карточке остался бы без шрифта. Плакат целиком набран
Playfair — иерархия держится кеглем и разрядкой, а не сменой гарнитуры.

## Источник и лицензия

Fontsource 5.3.0 (`@fontsource/playfair-display`,
`@fontsource/noto-sans-armenian`), файлы взяты из `files/` соответствующих
пакетов. Обе гарнитуры — SIL Open Font License 1.1, тексты лицензий лежат рядом:
`LICENSE-playfair-display.txt`, `LICENSE-noto-sans-armenian.txt`. OFL разрешает
распространение в составе продукта; шрифты не переименованы и не изменены.

Обновление: скачать одноимённые файлы из нужной версии пакета, положить сюда,
прогнать `npx playwright test e2e/open-graph.spec.ts` — тест сверяет, что
картинка отрисовалась и что в ней нет пустых прямоугольников вместо букв.
